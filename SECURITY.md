# Security policy

This policy covers the hosted Artifactry MCP connector at `https://mcp.artifactry.ai/mcp`, its OAuth sign-in, and the files in this repository.

## Reporting a vulnerability

Please report security issues privately, not in a public issue or pull request. Either:

- use GitHub's **Report a vulnerability** button on this repository's **Security** tab, or
- email [support@progredisystems.com](mailto:support@progredisystems.com) with "Security" in the subject line.

Include what you found, the steps to reproduce it, and the impact you expect. Test only against your own Artifactry account and data. Don't access, change or delete anyone else's data, and don't run tests that degrade the service for others.

We'll acknowledge your report and keep you updated while we investigate.
